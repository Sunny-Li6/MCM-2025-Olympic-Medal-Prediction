# MCM 2025 – Olympic Medal Prediction

## Overview

This project was completed for the 2025 Mathematical Contest in Modeling (MCM), Problem C.

We developed a modelling framework for predicting Olympic medal counts, estimating the probability of first-time medal-winning countries, and analysing the potential impact of elite coaching.

## Methods

- ARIMA time-series modelling
- Augmented Dickey–Fuller stationarity testing
- Logistic regression
- AUC-ROC validation
- Difference-in-differences
- OLS estimation
- Monte Carlo sensitivity analysis

## My Contribution

I led the data pipeline, including data collection, cleaning and harmonisation of historical Olympic records, and contributed to the development and evaluation of the predictive models.
